12 · preguntas frecuentes

Lo que suele preguntarse a destiempo

¿Qué es pickle?

No es un formato de datos. Es un programa que se ejecuta al abrirlo. Solo se deserializa lo que tiene procedencia conocida.

¿Por qué 503 y no 500 sin modelo?

500 dice "falló el servidor". 503 dice "no disponible, vuelve a intentar": un cliente con reintentos lo entiende.

¿Por qué el 422 sí lleva detalle?

Describe el request del cliente, no el interior del servidor. Es la única excepción a "no filtrar internals".

¿Por qué def y no async def?

model.predict bloquea. En una corrutina congela el event loop y el servidor atiende un request a la vez. Con def va a otro hilo.

¿Por qué no curl en el healthcheck?

No existe en python:slim. El check falla siempre y el contenedor queda unhealthy para siempre. Se usa el intérprete de la imagen.

¿Cuándo no hace falta nada de esto?

Si el consumidor es un reporte diario, el batch alcanza. No se monta una API para eso.

¿Por qué FastAPI en el curso?

No porque sea mejor: porque es la capa donde se ven los conceptos. Con volumen real, el paso siguiente es BentoML.

¿Por qué hay dos MLflow?

make mlflow (SQLite) y make up (Postgres y MinIO) comparten el puerto 5001 y no comparten el champion. Se usa uno a la vez.
